Class: PlatformNav

PlatformNav(level, settings)

The map of ways for the dark knight. It reads the level map into a network: the nodes are the cells where one can stand in the lowest rows, the edges are the ways from one to another, which are walking, falling and jumping. It finds the cheapest way to a goal and returns the next step. Jumps are simulated with the physics of the game, so they work exactly like in the game.
