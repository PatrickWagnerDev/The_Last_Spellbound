Class: World

World(canvas, keyboard, levelData, onGameEnd, characterId)

The running world of a level. It holds the level, the character, the projectiles, the display, the camera and the portal transition. It draws everything again for every frame, checks for the end of the game and knows the pause and the debug displays.

Builds the world: the level, the character at the start point, the links between all objects and the drawing loop.
